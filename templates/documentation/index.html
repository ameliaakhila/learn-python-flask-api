🚀 Pengenalan Flask

Apa itu Flask?

Flask adalah sebuah micro web framework berbasis Python yang dirancang untuk membangun aplikasi web dengan cara yang sederhana dan fleksibel. Framework ini sangat cocok untuk pemula karena memiliki dokumentasi yang baik dan kurva pembelajaran yang cukup mudah.

Karakteristik Flask:

  • ✅ Lightweight - Framework minimal tanpa fitur yang berlebihan
  • ✅ Fleksibel - Anda bebas memilih tools dan library yang diinginkan
  • ✅ Built-in Development Server - Server testing bawaan untuk development
  • ✅ RESTful Support - Mudah untuk membuat REST API
  • ✅ Jinja2 Templating - Template engine yang powerful
  • ✅ Werkzeug Integration - WSGI utility library yang robust

Kapan Menggunakan Flask?

Gunakan Flask ketika:
  • Membentuk aplikasi skala kecil hingga menengah
  • Membutuhkan fleksibilitas tinggi
  • Membuat REST API atau microservices
  • Ingin belajar web development dari dasar
Gunakan framework lain jika:
  • Membutuhkan banyak built-in features (gunakan Django)
  • Proyek sangat besar dan kompleks
  • Memerlukan ORM bawaan yang matang

📦 Instalasi & Setup

Langkah 1: Setup Virtual Environment

Virtual Environment adalah folder terisolasi yang berisi dependencies Python spesifik untuk project Anda. Ini sangat penting untuk menghindari konflik antar project.

# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate

Langkah 2: Install Flask

Setelah virtual environment aktif (perhatikan nama venv di awal terminal), install Flask dengan pip:

pip install flask

Langkah 3: Buat requirements.txt

File ini menyimpan list package yang digunakan di project:

pip freeze > requirements.txt

Struktur Folder Project

project/
├── venv/                    # Virtual environment
├── app.py                   # File aplikasi utama
├── requirements.txt         # Dependencies
├── static/                  # File statis (CSS, JS, images)
│   ├── style.css
│   └── script.js
└── templates/               # File HTML templates
    └── index.html

⚙️ Minimal Application

Aplikasi Flask Paling Sederhana

Berikut adalah struktur minimal aplikasi Flask yang bisa langsung dijalankan:

from flask import Flask

app = Flask(__name__)

@app.route('/')
def hello():
    return 'Halo, Dunia!'

if __name__ == '__main__':
    app.run(debug=True)

Menjalankan Aplikasi

python app.py

Aplikasi akan berjalan di http://localhost:5000

Penjelasan Kode:

  • from flask import Flask - Import module Flask
  • app = Flask(__name__) - Inisialisasi aplikasi Flask
  • @app.route('/') - Decorator untuk define route
  • def hello(): - Function yang handle request
  • app.run() - Menjalankan development server

🛣️ Routing & URL

Memahami Routes

Route adalah mapping antara URL dengan fungsi Python yang akan dijalankan.

Basic Routing

@app.route('/')
def index():
    return 'Home'

@app.route('/about')
def about():
    return 'About Page'

Dynamic Routes (URL Parameters)

@app.route('/user/<name>')
def greet(name):
    return f'Halo, {name}!'

# Contoh: /user/Amelia → "Halo, Amelia!"

Multiple Methods (GET, POST)

@app.route('/form', methods=['GET', 'POST'])
def form():
    if request.method == 'POST':
        # Handle form submission
        return 'Data diterima!'
    return 'Form page'

URL Building dengan url_for()

from flask import url_for

# Di template atau view
url_for('index')  # Menghasilkan '/'
url_for('greet', name='Amelia')  # Menghasilkan '/user/Amelia'

📝 Template & Rendering

Menggunakan Jinja2 Templates

Flask menggunakan Jinja2 sebagai template engine untuk render HTML dinamis.

Render Template dari View

from flask import render_template

@app.route('/hello/<name>')
def hello(name):
    return render_template('hello.html', 
                         nama=name, 
                         tahun=2024)

Template HTML (hello.html)

{% raw %}<!DOCTYPE html>
<html>
<body>
    <h1>Halo, {{ nama }}!</h1>
    <p>Tahun: {{ tahun }}</p>
    
    <!-- If Statement -->
    {% if tahun > 2023 %}
        <p>Tahun baru!</p>
    {% endif %}
    
    <!-- Loop -->
    <ul>
    {% for item in items %}
        <li>{{ item }}</li>
    {% endfor %}
    </ul>
</body>
</html>{% endraw %}

Template Inheritance (Base Template)

Untuk reusability, gunakan template base dan extend dengan child templates.

{% raw %}
<!DOCTYPE html>
<html>
<head>
    <title>{% block title %}Default Title{% endblock %}</title>
</head>
<body>
    <header>Navigation</header>
    
    <main>
        {% block content %}{% endblock %}
    </main>
    
    <footer>Copyright 2024</footer>
</body>
</html>{% endraw %}
{% raw %}
{% extends "base.html" %}

{% block title %}Home Page{% endblock %}

{% block content %}
    <h1>Selamat Datang!</h1>
    <p>Ini adalah konten halaman home.</p>
{% endblock %}{% endraw %}

📂 Static Files

Mengelola CSS, JavaScript, dan Images

Static files (CSS, JS, images) disimpan di folder static/ dan diakses dengan url_for().

Struktur Folder

project/
└── static/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── script.js
    └── images/
        └── logo.png

Menggunakan Static Files di Template

{% raw %}<!-- CSS -->
<link rel="stylesheet" 
      href="{{ url_for('static', filename='css/style.css') }}">

<!-- JavaScript -->
<script src="{{ url_for('static', filename='js/script.js') }}"></script>

<!-- Image -->
<img src="{{ url_for('static', filename='images/logo.png') }}" 
     alt="Logo">{% endraw %}

Mengapa menggunakan url_for()?

  • ✅ Otomatis adjust jika base URL berubah
  • ✅ Lebih aman dan maintainable
  • ✅ Support untuk file versioning (cache busting)

📥 Request Data

Mengakses Data dari Client

Flask menyediakan object request untuk mengakses data yang dikirim dari client.

GET Parameters (Query String)

from flask import request

@app.route('/search')
def search():
    # URL: /search?q=python&page=1
    query = request.args.get('q')
    page = request.args.get('page', default=1, type=int)
    return f'Search: {query}, Page: {page}'

POST Data (Form Data)

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    password = request.form.get('password')
    # Process login
    return 'Login success'

JSON Data (API)

@app.route('/api/data', methods=['POST'])
def api_data():
    # Request body: {"name": "John", "age": 30}
    data = request.get_json()
    name = data.get('name')
    age = data.get('age')
    return {'message': f'Hello {name}'}

# Return as JSON (otomatis di-serialize)
from flask import jsonify
return jsonify({'status': 'success', 'data': data})

Akses File Upload

@app.route('/upload', methods=['POST'])
def upload():
    file = request.files['file']
    if file:
        file.save(f'uploads/{file.filename}')
        return 'File uploaded'

📤 Responses & Error Handling

Jenis-jenis Response

String Response

@app.route('/')
def hello():
    return 'Hello World'

JSON Response

from flask import jsonify

@app.route('/api/users')
def get_users():
    users = [
        {'id': 1, 'name': 'Alice'},
        {'id': 2, 'name': 'Bob'}
    ]
    return jsonify(users)
    # atau: return jsonify({'users': users})

Custom Status Code & Headers

@app.route('/created', methods=['POST'])
def create():
    # Return dengan status code custom
    return 'Created', 201

# Dengan headers custom
return 'Success', 200, {'X-Custom-Header': 'value'}

Error Handling

Abort (Hentikan & Return Error)

from flask import abort

@app.route('/user/<id>')
def get_user(id):
    if not is_valid_user(id):
        abort(404)  # Not Found
    return f'User {id}'

Custom Error Handler

@app.errorhandler(404)
def page_not_found(error):
    return 'Page not found', 404

@app.errorhandler(500)
def internal_error(error):
    return 'Internal server error', 500

Redirect & HTML Response

from flask import redirect, url_for

@app.route('/old-url')
def old():
    return redirect(url_for('new_page'))

@app.route('/new-url')
def new_page():
    return 'New page'

🐛 Debug Mode

Mengapa Debug Mode Penting?

Debug mode memudahkan development dengan fitur-fitur seperti auto-reload dan interactive debugger.

Mengaktifkan Debug Mode

# Cara 1: Langsung di app.run()
app.run(debug=True)

# Cara 2: Environment variable
# Windows
set FLASK_ENV=development
set FLASK_DEBUG=1
flask run

# macOS/Linux
export FLASK_ENV=development
export FLASK_DEBUG=1
flask run

Fitur Debug Mode

  • ✅ Auto Reload - Server otomatis restart saat file berubah
  • ✅ Interactive Debugger - Console browser untuk debug error
  • ✅ Better Error Messages - Pesan error yang lebih detail
  • ⚠️ Security Risk - JANGAN gunakan di production!

Production Mode

Di production, debug mode HARUS dimatikan:

::app.run(debug=False)  # atau tidak usah debug parameter

🔐 Sessions & Cookies

Memahami Sessions

Sessions memungkinkan Anda menyimpan data user yang persisten across multiple requests.

Menggunakan Sessions

from flask import session
import secrets

app.secret_key = secrets.token_hex(16)

@app.route('/login', methods=['POST'])
def login():
    username = request.form.get('username')
    session['user'] = username  # Set session
    return 'Logged in'

@app.route('/profile')
def profile():
    user = session.get('user')  # Get session
    if not user:
        return redirect(url_for('login'))
    return f'Welcome {user}'

@app.route('/logout')
def logout():
    session.pop('user', None)  # Clear session
    return 'Logged out'

Cookies

Cookies adalah data yang disimpan di browser client.

from flask import make_response

@app.route('/set-cookie')
def set_cookie():
    resp = make_response('Cookie set')
    resp.set_cookie('user_id', '123', max_age=3600)
    return resp

@app.route('/get-cookie')
def get_cookie():
    user_id = request.cookies.get('user_id')
    return f'User ID: {user_id}'

🤖 API & Machine Learning

Membuat REST API dengan Flask

Flask sangat cocok untuk membuat REST API yang kemudian bisa diintegrasikan dengan ML model.

Contoh Simple ML Prediction API

from flask import request, jsonify
import numpy as np
from sklearn.linear_model import LinearRegression

# Train model (simplified)
X = np.array([[2, 100], [3, 150], [4, 200]])  # [kamar, luas]
y = np.array([300, 450, 600])  # harga (juta)
model = LinearRegression()
model.fit(X, y)

@app.route('/api/predict', methods=['POST'])
def predict():
    data = request.get_json()
    kamar = float(data['kamar'])
    luas = float(data['luas'])
    
    # Prediction
    X_input = np.array([[kamar, luas]])
    harga = model.predict(X_input)[0]
    
    return jsonify({
        'status': 'success',
        'harga_prediksi': round(harga, 2)
    })

Flow API Prediction

Client (JavaScript)
→ POST /api/predict
Flask API
→ Load Model
ML Model
→ Return JSON
Client (Display Result)

Memanggil API dari JavaScript

// JavaScript di frontend
fetch('/api/predict', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json'
    },
    body: JSON.stringify({
        kamar: 3,
        luas: 150
    })
})
.then(response => response.json())
.then(data => {
    console.log('Prediksi:', data.harga_prediksi);
    document.getElementById('result').textContent = data.harga_prediksi;
})
.catch(error => console.error('Error:', error));

🚀 Deployment

Menyiapkan Aplikasi untuk Production

Checklist Pre-Deployment

  • ☐ Set debug=False di app.run()
  • ☐ Gunakan secret key yang kuat
  • ☐ Set environment variable FLASK_ENV=production
  • ☐ Update requirements.txt dengan semua dependencies
  • ☐ Test aplikasi di environment production

Pilihan Deployment

1. Heroku

# Buat Procfile
echo "web: gunicorn app:app" > Procfile

# Login dan deploy
heroku login
heroku create nama-app
git push heroku main

2. PythonAnywhere

1. Upload file ke PythonAnywhere

2. Setup virtual environment

3. Configure WSGI file

4. Reload web app

3. Hosting VPS (AWS/DigitalOcean)

pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 app:app

# Gunakan Nginx sebagai reverse proxy
# Setup systemd service untuk auto-start

Production WSGI Server

Development server (Flask built-in) TIDAK cocok untuk production. Gunakan:

  • ✅ Gunicorn - Simple dan reliable
  • ✅ uWSGI - Lebih powerful dan flexible
  • ✅ mod_wsgi - Untuk Apache
